The Challenge
Why This Matters
Current R&D cost assessment analysis is manual, inconsistent, and cannot scale with the business.
⏱

Slow Turnaround

Heavy manual processing of Excel-based client deliverables creates bottlenecks, delays turnaround times, and limits the team's capacity to take on more work.

⚠️

Inconsistent Templates

Inconsistent Excel templates and unreliable file naming conventions make it difficult to reliably identify companies and match data across claims.

🔄

Double Counting Risk

No reliable deduplication or version control — multiple versions of the same claim create high risk of misattribution and double counting.

📉

Limited Portfolio Visibility

No portfolio-level analytics means management lacks strategic insight across the full book of business, limiting decision confidence.

The Product
What Cost Assessment Delivers
Deterministic automation prioritising data correctness, traceability, and decision-grade analytics.
01

Automated Extraction

Deterministic automation of compliant R&D cost assessment files. Only files meeting strict compliance rules are processed — no manual intervention.

02

Reliable Identification

Companies identified via registration number extracted from file content — never from file names or folder paths.

03

Normalised Data

Cost and benefit data normalised across all claims for consistent, comparable analytics — enabling true like-for-like analysis.

04

Smart Versioning

Automatic version resolution: highest version number always wins. Equal versions resolved by most recent timestamp. No silent overwrites.

05

Companies House Enrichment

Data enriched with official company name, country, SIC code, and standardised sector categories from the Companies House index.

06

Trusted Power BI Dashboard

Single dashboard delivering company-level, comparative, and portfolio analytics with filter-aware Excel and CSV exports.

Primary Output
The Dashboard — Three Levels of Insight
A single Power BI dashboard providing complete analytical coverage from individual claims to the full Leyton portfolio.
LEVEL 1

Single Company

Deep-dive analytics on one company's R&D claims

  • YoY trends in Tax Benefit (% growth)
  • YoY trends in Total Qualifying Expenditure (% growth)
  • Percentage breakdown of all 8 cost categories
  • YoY trends in cost category composition
  • Project-level expenditure breakdown by fiscal year
  • Multi-year projects split by year, not aggregated
Default view: last fiscal year. Users can select any year for comparison.
LEVEL 2

Comparative

Side-by-side analysis across multiple companies

  • Same full metric set as single company view
  • Up to 4 companies displayed side-by-side in dashboard
  • Compare by SIC code, company size band, cost band, or region
  • Benefit, expenditure & category YoY comparisons
  • Project spend YoY across selected companies
Exports: no limit — all claims for a period, sector, or matching criteria.
LEVEL 3

Leyton Portfolio

Full book-of-business strategic overview

  • Total Expenditure trend across the portfolio
  • Total Tax Benefit trend across the portfolio
  • Cost category trend across all claims
  • YoY comparative portfolio trends
  • Portfolio R&D intensity analysis
  • Normalised averages (avg. claim amount)
Two modes: total portfolio values and normalised averages.
